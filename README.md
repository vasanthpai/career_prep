# career_prep

My path from Roku developer to **Senior Full Stack Engineer with strong AI/ML skills** (LLM apps, RAG, agents, ML in production).

Target markets, in order: **Europe** (Germany, Netherlands, Switzerland) → **UAE** → **India remote**.

## How this repo works

| File / folder | What it is |
|---|---|
| [SKILLS.md](SKILLS.md) | **Source of truth** for skill levels. A level only goes up after the proof in the table is done. |
| [ROADMAP.md](ROADMAP.md) | The order I'm learning things in. No deadlines, just a sequence. |
| [learning/daily-log.md](learning/daily-log.md) | One short entry per day: what I learned, built, and got tested on. |
| `learning/notes/<topic>.md` | Revision notes from each topic thread ("wrap up"). |
| `mocks/<date>.md` | Mock interview transcripts and scores. |
| [interview/behavioral-stories.md](interview/behavioral-stories.md) | STAR stories built from real Roku and earlier work. |
| [resumes/base-resume.md](resumes/base-resume.md) | Master resume. Tailored versions are made from it per job. |

Jobs are tracked in a separate Job Tracker spreadsheet (tabs: Europe, UAE, India Remote), not in this repo.

## Skill levels

| Level | Meaning | Proof needed |
|---|---|---|
| Learning | Studying it now | Topic thread started |
| Working | Can use it with references | Passed basic mock (6+/10) |
| Senior | Designs, builds, debugs alone; explains trade-offs | Hands-on build task reviewed + senior mock (7+/10) |
| Top-tier | Architects at scale, mentors, survives deep follow-ups | Production-grade portfolio project + hard mock (8.5+/10) |

Only skills at **Senior or above** go on the resume or into job searches.

## Rules

- Consistency over intensity: learn something, build something, get tested on it, every day.
- No topic is done without code I wrote.
- Never invent experience, skills, metrics, titles or dates.
