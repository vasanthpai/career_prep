# ROADMAP.md

A sequence, not a schedule. Each phase is done when its skills reach the target level in SKILLS.md. Some days are one small exercise, some are a long session; both count.

## Phase 0 — Setup ✅ (2026-11-22)
- Repo structure, SKILLS.md baseline, Job Tracker.

## Phase 1 — Lock in what I already have
Goal: turn provisional levels into verified ones and build my story bank.
- `level up` Roku SceneGraph / BrightScript → Senior (verified).
- Write 6–8 STAR stories in `interview/behavioral-stories.md`.
- **Testing fundamentals from basics** (what/why/how to test, unit vs integration vs e2e, mocks), then apply to Rooibos/RTA in my daily Roku work. Real practice every workday.
- Target: Roku skills Senior ✅, stories drafted, testing → Working.

## Phase 2 — Modern frontend (refresh)
- JavaScript refresh → **TypeScript** (new).
- React refresh: hooks, state, React 19, Server Components, performance.
- Next.js App Router: routing, data fetching, caching, SSR/SSG/streaming.
- Testing: Vitest/Jest + React Testing Library, Playwright basics.
- BUILD: small typed Next.js app with tests.
- Target: TypeScript, React, Next.js → Senior.

## Phase 3 — Backend
- Node.js + an API framework (Express or NestJS/Fastify).
- REST API design: versioning, errors, pagination, idempotency, auth (sessions, JWT, OAuth).
- PostgreSQL: modelling, indexes, transactions, migrations; an ORM.
- Caching (Redis), background jobs, queues.
- BUILD: API with auth, DB, tests, deployed.
- Target: Node.js, SQL, API design → Senior.

## Phase 4 — AI/ML engineering
- LLM APIs: prompting, structured output, tool use, streaming, cost/latency.
- Embeddings + vector search; **RAG**: chunking, retrieval, reranking, evaluation.
- Agents: tool calling, planning loops, guardrails, failure modes.
- Evals & observability for LLM apps.
- ML fundamentals for production: data, training vs inference, monitoring, drift.
- BUILD: RAG app with evals.
- Target: LLM apps + RAG → Senior.

## Phase 5 — Production & system design
- Docker, one cloud (AWS or GCP), CI/CD I own end to end.
- Observability: logs, metrics, tracing.
- System design practice: requirements → estimates → design → deep dive → trade-offs.
- Target: system design → Senior.

## Phase 6 — Portfolio project (Top-tier proof)
- One production-grade full-stack AI app: TypeScript + Next.js + Node + Postgres + RAG/agents, tests, CI/CD, deployed, documented.

## Phase 7 — Job search (can start overlapping from Phase 4)
- Tailor resume per region, apply, track in Job Tracker.
- Remember the 90-day notice period when planning start dates.

## Running in parallel, every phase
- DSA: a little most days.
- Behavioral: one story polished per week.
- Daily log entry.
